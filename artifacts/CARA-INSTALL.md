# Pasang Belanja di Android

1. Salin **Belanja-0.1.0-debug.apk** dari folder ini ke HP Android, misalnya melalui kabel USB.
2. Buka file APK lewat aplikasi **Files / File Saya** di HP.
3. Jika Android meminta izin, aktifkan **Izinkan dari sumber ini** untuk aplikasi Files yang sedang digunakan.
4. Tap **Instal**, lalu buka **Belanja** dari layar aplikasi.
5. Coba tambah barang, ceklis semuanya, lalu simpan ke Riwayat. Scan struk bisa dilakukan lewat kamera atau galeri.
6. Coba mode pesawat: daftar, riwayat dan OCR sudah disertakan dalam APK, jadi tidak perlu mengunduh aset terlebih dahulu.

Versi ini adalah APK **debug untuk uji pribadi**, bukan rilis Play Store. Minimum Android 7 dengan Android System WebView yang diperbarui.

Data disimpan lokal di aplikasi. Data dari versi browser/PWA tidak otomatis masuk ke APK. Menghapus data aplikasi atau uninstall akan menghapus list, riwayat dan foto. Untuk update berikutnya, pasang APK baru di atas aplikasi lama.
